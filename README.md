# COSA AI v2.0 — Your Intelligent World

منصة ذكاء اصطناعي متكاملة: واجهة + خادم آمن + حسابات + اشتراكات + صوت + ملفات.

## المتطلبات
- Node.js 18 أو أحدث: https://nodejs.org
- مفتاح Groq جديد: https://console.groq.com/keys (المفتاح القديم أُلغي لأنه نُشر علناً — أنشئ واحداً جديداً)

## التشغيل المحلي (5 دقائق)

```bash
# 1) افتح مجلد المشروع
cd cosa-ai

# 2) ثبّت الاعتماديات
npm install

# 3) جهّز الإعدادات
cp .env.example .env
# ثم عدّل .env: ضع مفتاح Groq الجديد، وغيّر JWT_SECRET وMASTER_CODE

# 4) شغّل الخادم
npm start
```

افتح المتصفح على: `http://localhost:3000`

> وضع الاختبار: إذا تركت `GROQ_API_KEY=mock` سيشتغل التطبيق بردود وهمية للتجربة فقط، دون استهلاك رصيد.

## النشر على الإنترنت (مجاناً — Render.com)

1. أنشئ حساباً على https://render.com
2. ارفع مجلد المشروع إلى GitHub (خاص Private)
3. في Render: **New → Web Service** → اربط المستودع
4. اضبط:
   - Build Command: `npm install`
   - Start Command: `node server/server.js`
5. أضف متغيرات البيئة (Environment) من ملف .env:
   `GROQ_API_KEY`، `JWT_SECRET`، `MASTER_CODE`، `ADMIN_EMAIL`، `WHATSAPP_NUMBER`
6. بعد النشر ستحصل على رابط مثل `https://cosa-ai.onrender.com`

**تحديث تطبيق APK الحالي:** وجّه WebView في تطبيقك إلى رابط Render الجديد بدلاً من ملف HTML المحلي.

## الإعدادات المهمة في .env

| المفتاح | الوصف |
|---|---|
| `GROQ_API_KEY` | مفتاح Groq — **سرّي، على الخادم فقط** |
| `JWT_SECRET` | سر عشوائي طويل لتوقيع الجلسات |
| `MASTER_CODE` | كودك الشخصي الدائم (غيّره!) |
| `ADMIN_EMAIL` | أول حساب يُسجّل بهذا البريد يصبح مديراً |
| `FREE_DAILY_LIMIT` | حد الرسائل المجانية (افتراضي 35) |
| `PRICE_MONTHLY_MAD` / `PRICE_YEARLY_MAD` | الأسعار بالدرهم |

## لوحة الإدارة

1. سجّل حساباً بالبريد المحدد في `ADMIN_EMAIL`
2. في التطبيق، اضغط على **شعار COSA AI 5 مرات متتالية**
3. ستظهر: الإحصاءات + إصدار أكواد التفعيل (شهري/سنوي/VIP)
4. بِع الأكواد للمشتركين — كل كود يعمل **مرة واحدة فقط**، والتحقق كله على الخادم

## طريقة الدفع (حالياً)

الدفع يتم يدوياً عبر واتساب (كما في نظامك الحالي): المستخدم يضغط "💳 دفع الاشتراك" → يتواصل معك → يحوّل المبلغ → ترسل له كود تفعيل من لوحة الإدارة → يفعّله فيصل تلقائياً.

> دمج بوابة دفع مغربية (CMI) يتطلب حساباً تجارياً لدى البنك — البنية جاهزة لإضافته لاحقاً في `server/server.js`.

## ما الذي تغيّر أمنياً عن النسخة القديمة؟

| قبل (HTML فقط) | الآن (خادم + واجهة) |
|---|---|
| مفتاح Groq داخل HTML مكشوف | المفتاح في `.env` على الخادم فقط |
| 300 كود تفعيل قابلة للتخمين داخل JS | أكواد عشوائية 12 خانة تُولَّد على الخادم |
| MASTER_CODE داخل الواجهة | في `.env` — لا يظهر أبداً |
| الاشتراك والعداد في localStorage (قابل للتلاعب) | محفوظان على الخادم مع JWT |
| Firebase Rules مكشوفة | لم نعد بحاجة إلى Firebase — قاعدة البيانات على الخادم |
| لا حدود حقيقية | Rate Limiting + عداد يومي على الخادم |
| Markdown خام (XSS ممكن) | Markdown معقّم عبر DOMPurify |

## بنية المشروع

```
cosa-ai/
├── server/
│   ├── server.js      ← الخادم (مسارات API + Streaming + Groq + Whisper)
│   └── db.js          ← قاعدة البيانات (JSON) والأكواد والعدادات
├── public/
│   ├── index.html     ← الواجهة
│   ├── style.css      ← التصميم (فاتح/داكن/RTL)
│   └── app.js         ← منطق الواجهة (بلا أي مفاتيح)
├── data/db.json       ← تُنشأ تلقائياً (المستخدمون/المحادثات/الأكواد)
├── .env               ← الإعدادات السرية (لا ترفعه لـ GitHub العام)
└── package.json
```

## الميزات المفعّلة فعلياً

- محادثة نصية Streaming مع Markdown وزر إيقاف ونسخ وإعادة توليد وتعديل
- سجل محادثات كامل: حفظ تلقائي، بحث، حذف، استرجاع
- حسابات: تسجيل/دخول/خروج/حذف + وضع ضيف
- صوت: ميكروفون (Whisper عبر Groq) + قراءة الإجابات (TTS) + وضع COSA Voice الكامل
- صور: رفع وتحليل (Llama 4 Vision) — للمشتركين Pro
- ملفات: PDF / Word / نصوص / أكواد — للمشتركين Pro
- اشتراكات Free/Pro مع أكواد تفعيل أحادية الاستخدام
- لوحة إدارة: إحصاءات + إصدار أكواد (محمية بصلاحيات خادمية)
- وضع ليلي، حجم خط، سرعة قراءة، لغة التعرف على الكلام
- حماية: Helmet + Rate Limiting + bcrypt + JWT + تعقيم المدخلات
